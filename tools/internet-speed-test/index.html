Internet Speed Test: check your broadband or mobile connection

Use this free browser-based speed test to estimate internet latency, download throughput, upload throughput and jitter. The test uses a Cloudflare speed-test endpoint and does not require an account.

How to get a better speed test result

Pause large downloads and video streams, move closer to your Wi-Fi router, and run the test more than once at different times. Compare results using the same device and network.

Understanding the results

Ping measures response time in milliseconds; lower is generally more responsive. Download speed measures how quickly data reaches your device. Upload speed measures how quickly your device sends data. Jitter describes variation in response time.

Frequently asked questions

Does this show my ISP or public IP address?

No. This version does not display or save your public IP address or ISP details.

Is this an official TRAI speed test?

No. This is an independent browser-based test for general guidance and is not a TRAI-certified measurement.

Why can results vary?

Wi-Fi signal, network congestion, device performance, VPNs, background downloads and the selected test endpoint can affect the result.
